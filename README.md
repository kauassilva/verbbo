# Verbbo 🔤

**Verbbo** é um compilador desenvolvido em **Java**, criado com o objetivo de explorar os fundamentos da construção de compiladores — desde a análise léxica até a geração de código.  
O projeto ainda está em fase inicial, mas vai evoluir aos poucos, ganhando novas funcionalidades e melhorias.

---

## 🚀 Objetivo

Construir um compilador funcional, didático e modular, que possa:
- Analisar código fonte em uma linguagem simples (estilo pseudo-código);
